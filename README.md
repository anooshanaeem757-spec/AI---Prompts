# AI---Prompts
This repository contains 5 AI prompts created for learning and productivity tasks. These prompts are written using WHAT, HOW, and WHY structure.
Prompt 1
WHAT:
Create a professional CV for a fresh Computer Science student.
HOW:
Use simple English and professional formatting.
WHY:
I want to apply for internships.
Prompt 2
WHAT:
Write a LinkedIn post about learning MERN Stack.
HOW:
Use simple and friendly wording.
WHY:
I want to grow my professional network.
Prompt 3
WHAT:
Prepare a short self-introduction for a Computer Science student interview.
HOW:
Make it simple, confident, and easy to speak in 60 seconds.
WHY:
To answer “Tell me about yourself” in interviews.
Prompt 4
WHAT:
Write an email to apply for a software development internship.
HOW:
Use formal and polite English with clear structure.
WHY:
To apply for internships at companies.
Prompt 5
WHAT:
Create a simple project description for a To-Do List App.
HOW:
Use easy English and bullet points for features.
WHY:
To add in CV or portfolio.
